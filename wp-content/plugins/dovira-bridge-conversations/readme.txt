Дає Dovira Bridge (Dovira Pro) читати звернення сайту і змінювати їх статус «оброблено / не оброблено».

== Description ==

Плагін додає до REST API сайту простір `dovira-bridge/v1` для типу записів «conversation» (Звернення):

* `GET /wp-json/dovira-bridge/v1/describe` — опис типу записів: статуси (зокрема власні), таксономії з термінами,
  поля (meta, зокрема ACF — з назвами й варіантами), кількість записів за статусами. За ним у Bridge видно, де
  зберігається позначка «оброблено».
* `GET /wp-json/dovira-bridge/v1/conversations?modified_after=<дата UTC>&page=1&per_page=50` — звернення,
  змінені після дати (від найдавніших), до 100 на сторінку.
* `GET /wp-json/dovira-bridge/v1/conversations/<id>` — одне звернення.
* `POST /wp-json/dovira-bridge/v1/conversations/<id>/status` з тілом `{"field_kind": "post_status" | "meta" | "taxonomy",
  "key": "...", "value": "..."}` — змінює статус запису, поле або термін таксономії.

Усі маршрути доступні лише користувачу з правом редагувати чужі звернення (`edit_others_conversations`; якщо такого
права на сайті немає — `edit_others_posts`). Вхід — пароль застосунку (Профіль → «Паролі застосунків»).

Щоб Bridge бачив зміни поля чи терміна, зроблені не через редактор (наприклад, перемикачем у списку), плагін
оновлює час зміни такого звернення.

Плагін не зберігає власних даних і нічого не видаляє: деактивація чи видалення нічого не змінює на сайті.

== Installation ==

1. «Плагіни → Додати новий → Завантажити плагін», оберіть `dovira-bridge-conversations.zip`, «Встановити», «Активувати».
2. Користувачі → профіль користувача з роллю «Customer support specialist» (або іншою з правом редагувати
   звернення) → «Паролі застосунків» → назва «Dovira Bridge» → «Додати новий пароль застосунку». Скопіюйте пароль.
3. У Dovira Bridge: Інтеграції → «Сайт dovira.vet» → з’єднання «Сайт WordPress (звернення)»: логін цього
   користувача і пароль застосунку; «Перевірити».
